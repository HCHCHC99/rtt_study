# 欠压保存位置及首次校准

> 日期：2026-09-10（2026-09-14 随转动机构模式更新：单位=度、行程 88、机械参数入 Flash A 块）　关联代码：`Dev/dev_param/dev_param_rod.c`、`Utils/param_manager.c`、`Dev/dev_state.c`、`Task/rod_task.c`、`Dev/dev_rod/dev_rod_calib.c`
> 配套流程图：`ob/欠压保存位置及首次校准.canvas`

## 1. 系统目标

- **掉电记忆行程**：真实掉电（欠压）时把当前行程写入 Flash B 块，上电恢复 `position_mm` 并置 `CALIBRATED`，电机霍尔增量在其基准上继续累加（数值单位=度，转动机构模式，行程 0~88°）。
- **未校准不伪装**：从未建立位置基准的板子，上电必须保持未校准态（走首次校准流程），任何路径都不得把"假行程"标成已校准。

## 2. 欠压保存链路（运行期）

| 步骤 | 实现 | 说明 |
|---|---|---|
| ① 欠压检测 | 1ms ISR（`dev_bus_voltage.c`） | 欠压阈值瞬时判定 → `EVT_SYS_VOLT_UNDER` |
| ② SeenValid 门控 | dispatch（`dev_state.c` 欠压分支） | `BusVoltage_HasSeenValid()==0`（3.3V 调试、从未见过有效母线）→ 不请求，防调试污染；`=1` → `Dev_Param_RodSaveRequest()`（幂等，欠压持续期重复事件不重复置位） |
| ③ 延时执行 | rod_task 10ms → `Dev_Param_RodPollSave()` | 请求后计 2 tick ≈ **20ms**（等 EMERGENCY 刹车滑行稳定），非阻塞 |
| ④ 校准门控 | PollSave 内（本次新增） | `!RodPosition_IsCalibrated()` → skip（打印 `save skipped: position NOT calibrated`），防假基准落盘 |
| ⑤ 写 Flash | `Dev_Param_RodSave()` → `Param_Save` | 写 B 块（扇区 60→51，24B 追加写），seq+1，CRC32 校验 |

**时间预算**：欠压边沿 → 写完 ≈ 20ms 延时 + ≤8ms 写入 ≈ **30ms 内**；实测欠压后 MCU 电容维持余量 ~270ms，充裕。

**并发时序**（欠压 + 过流校准同时发生）：SaveRequest 先挂起 → rod_task 先消费 `calib_req` 重置位置（10ms 内）→ 20ms 后 PollSave 保存的是**校准后的正确值**（0 或 stroke）。

## 3. 上电恢复链路（启动期）

```
main → Dev_Param_RodInit → Param_Init(B块)：逐块 magic+CRC32 校验，取 seq 最大者
  ├─ 有有效记录 → 加载到 s_rod_record
  └─ 无有效记录 → SetDefaults（position=0，走首次校准流程）+ 默认落盘（引擎行为，seq=1）
App_Model_Init → Dev_Param_RodApply：
  ① 校准窗口 a~d + stop_margin 写入 + 机械参数 SetParams（stroke/ratio/pulses/lead，
     A 块值覆盖 DFT 初值——无论恢复与否都要就位）
  ② defaults_written → skip（本机刚 defaults，无有效块）
  ③ seq<=1 → skip（默认落盘记录，非真实保存，防假校准）★新增
  ④ 通过 → position_mm 恢复 + CALIBRATED
```

**seq 语义**（关键）：

| seq 值 | 来源 | 可信度 |
|---|---|---|
| 1 | `Param_Init` 默认落盘（`SetField32(seq=0)` 后 `Param_Save` 内部 +1 写入） | 假记录，行程是默认值，从未校准 |
| ≥2 | 真实欠压保存（RAM 中 seq 1 + 1 = 2 起，逐次递增） | 可信，保存时必已校准（被 ④ 门保证） |

恢复层 `seq<=1` 拒绝 ↔ 保存层仅校准后写入 → **闭环**：Flash 里 seq≥2 的记录必然来自已校准时刻，恢复置 CALIBRATED 才有依据。

## 4. 首次校准流程（未校准态）

- **初始行程值**：`RodPosition_Init` 置 `position_mm=0`（假基准），随霍尔脉冲累加但**无物理意义**。
- **不污染校准**：校准重置是无条件赋值（`OnMinLimit→0` / `OnMaxLimit→stroke`），过流前的漂移值被完全丢弃。
- **方向判定**（`RodCalib_OnOverCurrent`，dispatch 线程）：
  - 未校准（`!IsCalibrated`）或位置在下限窗口（`pos<=calib_win_a/b`）或上限窗口（`pos>=calib_win_c/d`）→ 软限位校准，不算故障；
  - 窗口外（已校准且位置在中间）→ 异物卡住真故障 → EMERGENCY。
- **执行**（rod_task 消费 `calib_req`）：
  - **伸出中过流（FWD）→ REQ_MAX → position = stroke(88°) + CALIBRATED**（顶到上限，窗口 pos≥86°）
  - **缩回中过流（REV）→ REQ_MIN → position = 0 + CALIBRATED**（顶到下限，窗口 pos≤2°）
- **校准不落盘**：校准本身只改 RAM；需经历一次真实掉电（欠压保存）才持久化。中途复位 → 回未校准态重新走校准流程（现状设计）。

## 5. 本次修复的两个"伪装校准"漏洞

### 漏洞 1：默认落盘 → 上电假校准
全片擦除后首次上电，`Param_Init` 把默认行程（`PARAM_ROD_STROKE_DFT`=0，历史版本曾为满量程值）写成有效记录落盘（seq=1）；**第二次上电起**恢复分支无条件 `CALIBRATED + 该值`。若该值为满量程（如旧版 1000mm），后果：未校准板伪装到上限位 → 位置停车判定 `1000 ≥ 996` → 上电即 EXT_LIMIT 禁正转。现默认 0 时表现为"恢复 0° 已校准"，同样属假基准，仍由 seq<=1 门拦截。
**修复**：RodApply 增加 `seq<=1 → skip` 门。

### 漏洞 2：未校准欠压保存假基准
PollSave 不查校准状态：未校准（position=0 假基准漂移）时欠压 → 保存漂移值 → seq≥2 → 下次上电恢复"已校准+错误行程"，seq≤1 门挡不住。
**修复**：PollSave 增加 `!IsCalibrated → skip` 门。

## 6. 防护链总表

| 层 | 机制 | 防什么 |
|---|---|---|
| dispatch（欠压沿） | `SeenValid==0` 不请求 | 3.3V 调试无母线，不触发保存 |
| PollSave（写前） | `!IsCalibrated → skip` ★ | 未校准假基准落盘 → 假校准记录 |
| RodApply（恢复前） | `defaults_written` / `seq<=1 → skip` ★ | 默认落盘记录被当成真实校准恢复 |

## 7. 测试要点（全片擦除后）

| 步骤 | 预期日志 | calib_state | B 块 seq |
|---|---|---|---|
| 第 1 次上电 + 3.3V | `defaults set` → `Defaults saved` → `apply skipped (no valid block)` | 0（未校准） | 1（默认落盘，position=0） |

## 8. 已知设计边界

- 校准本身不落盘：校准后必须经历一次真实掉电才持久化（若要"校准即保存"需另加请求链路）。
- 残余无害项：全擦后首次上电仍会写一条 seq=1 默认记录进 B 块，但每次加载都被恢复层拒绝，直到真实保存覆盖。
- 3.3V 纯调试全程不写 B 块（SeenValid 门 + 校准门双保险）。
