## 三、dev_hall_rod（推杆霍尔设备模块）

- **引脚**（从 `dev_rod_state.h` 迁入本模块头文件）：
  `ROD_HALL_MAX_PIN = GET_PIN(B, 2)`（上限位）、`ROD_HALL_MIN_PIN = GET_PIN(B, 10)`（下限位），高电平=触发；
- **消抖**：仿 `dev_polarity` 双窗口，每路 3 点窗口（10ms 扫描 → 30ms 稳定判定），窗口未满/不稳定保持上次稳定态；
- **读取**：`rt_pin_read`（与 dev_polarity 一致，弃用 `Hc32_Gpio_Read`）；
- **接口**：
  - `void RodHall_Init(void)` —— 复位窗口与状态（registry IDLE 入口统一 init）；
  - `void RodHall_Scan(void)` —— 读 GPIO + 推窗 + 判定（rod_task 10ms 调，单例非 per-axis）；
  - `bool RodHall_IsAtMax(void)` / `bool RodHall_IsAtMin(void)` —— 消抖后稳定限位态；
  - `bool RodHall_IsFault(void)` —— 双高（消抖后）异常态；
- **故障归属**：双高消抖后**上升沿**由本模块发 `Sys_Event_Send(EVT_SYS_ROD_LIMIT_FAULT)`（→系统 EMERGENCY + fault_bits），只发跳变沿。

## 四、dev_hall_motor（电机霍尔设备模块，完整移植参考代码）

- **引脚与 EXTI**（与参考工程一致，PA9/PA10）：
  - GPIO 输入+上拉，`EXTINT_CH09/CH10` 双边沿（`EXTINT_TRIG_BOTH`）、中断 `INT009/INT010_IRQn`、源 `INT_SRC_PORT_EIRQ9/EIRQ10`（本工程 DDL 命名），优先级 `DDL_IRQ_PRIORITY_02`；
  - 注册流程照搬参考 `register_hall_irq`：`EXTINT_Init` → GPIO 输入 → `GPIO_ExtIntCmd`（含 `LL_PERIPH_WE/WP` 写保护）→ `INTC_IrqSignIn` → NVIC；
- **计数**：每路独立计数（ISR 内无条件 ++，对应参考 `hall_pulse_counts[2]`）；电机每机械转 12 边沿（3 极对 × 2 霍尔 × 2 边沿）；
- **判向**（与参考完全一致）：**B 下降沿时采样 A 电平**——A 高=REV、A 低=FWD（反转全局量 `g_mothall_invert_dir`，默认取宏 `MOTOR_HALL_DIRECTION_INVERT_DEFAULT`，Watch 可改）；连续 3 次不一致才切换（`DIRECTION_CONFIRM_COUNT=3`）；`current_rpm==0` 时跳过判向（同参考）；方向 NONE/STOP 时增量回退 `last_valid_direction`；
- **速度链路（与参考完全一致，全量移植）**：
  - us 时基：`Timer6_Timebase_GetDelta/DeltaToUs/GetTimestamp/UpdateTimestamp`（本工程 `Adp/hc32_drv_timer.h` **同名接口**，main.c 已 Bind/Init/Start，无需新外设）；
  - 脉冲间隔过滤 `MIN_PULSE_INTERVAL_US=50 / MAX_PULSE_INTERVAL_US=200000`；
  - interval 历史 6 点平均 → `interval_to_rpm`（`60000000/(interval×pulses_per_rev)`，上限 100000rpm）；
  - RPM 滑动窗口 6 点滤波（`RPM_WINDOW_SIZE=6`，10ms 周期 `calculate_rpm`，对应参考 `nbDelay 10ms`）；
  - `pulses_per_rev = pole_pairs(3) × 2 × active_halls`（或 `custom_pulses_per_rev`）；
- **状态检测（与参考完全一致，可查询观测）**：
  - `perform_stall_detection`：无脉冲 >50ms → 停止/方向清 STOP；>500ms → `stalled=1`、RPM 清零（对应 `STOP_DETECTION_MS/STALL_DETECTION_MS`）；
  - `check_hall_status`：1000ms 周期，A/B 计数差 >10% → `HALL_STATUS_ERROR`，单路 → A_ONLY/B_ONLY（`HALL_CHECK_INTERVAL_MS=1000`、`HALL_WARNING_THRESHOLD=10`）；
- **接口**（`MotorHall_` 前缀，对应参考 API 一一映射）：
  - `void MotorHall_Init(void)` —— 首次调用注册 EXTI（`s_hw_ready` 防重复登录），之后每次 IDLE 进入仅复位业务状态（对应参考 create/reset 分离）；
  - `void MotorHall_Task(void)` —— 10ms 调用（rod_task 编排，对应参考 `motor_hall_update`：更新时基 + 10ms 测速/堵转 + 1s 霍尔状态 + 增量累积）；
  - `int32_t MotorHall_GetDeltaPulses(uint8_t axis_id)` —— 取走带符号增量（读清）；per-axis 静态数组（不用 malloc，对应参考 `g_s32HallPulseAccum`），当前仅 axis0 实接；
  - `float MotorHall_GetRpm / GetRpmRaw`、`uint32_t GetPulseIntervalUs`、`MotorHallDir_t GetDirection`、`uint8_t GetDirectionConfidence`、`uint8_t IsDirectionChanged`（读清）、`uint32_t GetHallACount/GetHallBCount/GetTotalPulseCount`、`void ResetCounts`、`MotorHallStatus_t GetStatus`、`uint8_t GetActiveHallCount`、`uint16_t GetPulsesPerRev`、`uint8_t IsRunning`、`uint8_t IsStalled`；
- **边界（用户框架约束，两次确认）**：
  - 未接入/无信号 → RPM=0、delta=0，**不报错、不置任何故障位、不发任何事件**；
  - stalled/is_running/HALL_STATUS 仅作**查询接口**（观测/调试/后续备用），本工程**任何模块不得据此触发故障/急停**；堵转判定后续由过流实现；
  - 判向不依赖仲裁方向；
- **移植裁剪清单**（Adp+Dev 两层合并为单设备模块 `Dev/dev_hall_motor`）：
  - 不移植：device_manager 框架（ops/CMD 命令字）、EventBus 发布（`TOPIC_MOTOR_SPEED_FEEDBACK`）、malloc/create 实例管理（改 per-axis 静态数组）、`TickTimer/timer6_timebase/NonBlockingDelay` 依赖（改 `rt_tick_get_millisecond()` + 本工程同名 Timer6_Timebase）、`App_Params`；
  - 适配：打印走 `rtt_manager.h`（`HALL_MOTOR_PRINT`，英文；RPM 用 ×10 拆整型打印，同参考 `rpm_to_int`，无浮点打印）；宏全部放 .h（规范 §11）。

## 五、dev_rod_position（位置模块，修剪为纯算法）

- 算法不动：`Update(带符号增量)` 脉冲→mm 积分、`OnMinLimit/OnMaxLimit` 限位校准、校准区管理；
- **语义收窄**：`in_calib_zone_min/max` 只用于校准允许门控，**不再被状态模块当限位信号**（删掉状态机的位置合成限位）。

## 六、dev_rod_state（状态模块，修剪为纯算法）

- 删除：引脚宏（迁 dev_hall_rod.h）、`RodStateCtx_t.max_limit_switch/min_limit_switch`、`RodStateCtx_t.min_velocity_thresh`（堵转阈值作废）、`RodState_SetSensorFault()`（双高故障沿事件改由 RodHall 模块发）；
- 事件源修改（`RodState_Update` 内直接调 RodHall 接口，include `dev_hall_rod.h`）：
  - `AT_MAX` = `RodHall_IsAtMax()`，`AT_MIN` = `RodHall_IsAtMin()`（纯霍尔稳态）；
  - `SENSOR_FAULT` = `RodHall_IsFault()`；
- 不变：跳转表 `s_rod_jump`、限位事件发送（`EVT_ROD_LIMIT_EXTEND/RETRACT/RELEASED` → `Act_Event_Send`）、
  **5000ms 指令级超时**（发了方向指令但一直没到限位 → EXT/RET_FAULT；与电机霍尔无关）；
- 堵转检测：本模块不做（后续过流实现，另行设计）。

## 七、rod_task（编排，10ms）

```c
MotorHall_Task();                                  /* 测速/堵转观测/霍尔状态/增量累积（对应参考 update） */
RodHall_Scan();                                    /* 消抖 + 双高故障沿检测 */
for (i = 0; i < MAX_AXIS_NUM; i++) {
    delta = MotorHall_GetDeltaPulses(i);           /* 带符号增量 */
    RodPosition_Update(&axis->position, delta);
    RodPosition_OnMinLimit(&axis->position, RodHall_IsAtMin());   /* 校准 */
    RodPosition_OnMaxLimit(&axis->position, RodHall_IsAtMax());
    Arb_GetData(i, &arb) → dir;                    /* 禁用/失败视为停止 */
    RodState_Update(&axis->sm_act, &axis->state, dir, tick);
}
```

删除：GPIO 读取、双高判定、`Hall_GetDeltaPulses` 弱定义。

## 八、数据流

```
PA9/PA10 EXTI ─► MotorHall ISR 计数（B 下降沿采样 A 判向）
                              │ GetDeltaPulses（带符号）
PB2/PB10 10ms ─► RodHall_Scan（消抖）─► IsAtMax/IsAtMin/IsFault
                              │              └─双高沿─► EVT_SYS_ROD_LIMIT_FAULT ─► EMERGENCY
Arb_GetData 方向 ─────────────┼──► rod_task（10ms 编排）
                              ▼
        RodPosition_Update / OnMinLimit / OnMaxLimit（校准）
                              ▼
        RodState_Update（状态机：AT_MAX/AT_MIN=霍尔稳态，超时，故障）
                              ▼
        Act_Event_Send(EVT_ROD_LIMIT_EXTEND/RETRACT/RELEASED) ─► 仲裁
```

## 十、错误检测源边界（用户两次确认）

- **是错误源**：推杆霍尔双高（→EMERGENCY）、电源类保护（过压/欠压/过流/极性异常）；
- **不是错误源**：电机霍尔——完整移植的速度/堵转/双霍尔状态检测全部只作**可查询观测量**，
  任何模块不得据此触发故障/急停；堵转后续由过流判断（另行设计）。
