## 二、推杆位置模块（dev_rod_position）

**结构** `RodPosition_t`：`position_mm / calib_state / calib_pending / calib_allowed / in_calib_zone_min/max / stroke_mm / reduction_ratio / pulse_to_mm / calib_tolerance_mm`

**接口**：`Init / SetParams / Update / OnMinLimit / OnMaxLimit / GetCurrent / IsCalibrated / IsCalibAllowed / IsInCalibZoneMin/Max`

**参数**（`App_Model_Init` 配置）：
- 行程 1000mm、减速比 10、每机械转 12 边沿（双霍尔三极性）、导程 10mm/圈、校准容差 3mm；
- `pulse_to_mm = 导程/(减速比×每转脉冲) = 10/(10×12) = 0.0833 mm/脉冲`。

**校准逻辑**：
- 上电未校准：`calib_allowed = Enable`（允许首次校准）；
- 碰下限位 → 位置=0、碰上限位 → 位置=1000，置 `POSITION_CALIBRATED`；
- 已校准后：`calib_allowed = 在校准区（[-3,3] 或 [997,1003]）`，跑出校准区 → Disable。

## 三、推杆状态模块（dev_rod_state）

**状态**：`UNKNOWN / STOPPED / EXTENDING / EXT_LIMIT / EXT_FAULT / RETRACTING / RET_LIMIT / RET_FAULT`

**事件**（10ms tick 合成，优先级：传感器异常 > 限位 > 超时 > 方向指令）：
`CMD_STOP / CMD_EXTEND / CMD_RETRACT / AT_MAX / AT_MIN / TIMEOUT / SENSOR_FAULT`

**机制**：
- 表驱动：`s_rod_jump[]` 跳转表 + `Axis_t.sm_act`（state_engine）；侧效应（计数/限位事件/move_start_tick）在 `RodState_Update` 按跳变处理；
- 未校准也允许运动（寻找限位→自动校准）；
- 限位到达 → `Act_Event_Send(EVT_ROD_LIMIT_EXTEND/RETRACT)`，离开 → `EVT_ROD_LIMIT_RELEASED`（通知仲裁）；
- 运动超时 5000ms → EXT/RET_FAULT；堵转（0.5mm/s）预留（霍尔未接）；
- **双高异常**（上下霍尔同时触发）→ `RodState_SetSensorFault` → `EVT_SYS_ROD_LIMIT_FAULT` → 系统 EMERGENCY + `fault_bits` bit3。

## 四、电机仲裁占位（dev_act）

- 接口：`Act_Arbitrator_Init()` / `Arbitrator_GetDirection(axis_id)`；
- 当前返回全局 `volatile RodDirection_t g_act_dir`（默认 STOP，Watch 可改：0停/1伸/-1缩）；
- 后续真实仲裁（极性×指令×限位×过流）依据 `裸机电机仲裁系统.md` / `gpt_电机仲裁系统模块.md` 实现。

---

## 五、推杆周期任务（rod_task，10ms）

`Actuator_Tick`：每轴
1. `Hall_GetDeltaPulses(i)`（**RT_WEAK 占位返回 0**，霍尔模块提供后自动覆盖）→ `RodPosition_Update`；
2. 读限位 GPIO（上 PB2 / 下 PB10，高=触发）；
3. 限位注入位置模块（自动校准）；
4. 双高 → `RodState_SetSensorFault`；
5. `Arbitrator_GetDirection` → `RodState_Update`。

## 七、数据流

```
霍尔脉冲(占位0) ─┐
限位GPIO(PB2/PB10)─┼─► Actuator_Tick(10ms) ─► RodPosition_Update(位置/校准)
方向指令(g_act_dir)─┘        │
                             ▼
                     RodState_Update(状态机)
                             │
                 限位事件(EVT_ROD_LIMIT_*) / 传感器异常(EVT_SYS_ROD_LIMIT_FAULT)
                             │ Act_Event_Send / Sys_Event_Send
                             ▼
                   仲裁(占位) / 系统状态机(EMERGENCY)
```
