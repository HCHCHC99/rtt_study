# 转动机构模式改造

> 日期：2026-09-14　关联代码：`Dev/dev_mgr/dev_model.c`、`Dev/dev_param/*`、`Dev/dev_power/dev_cur_sensor.*`、`Dev/dev_gpio_motor/*`
> 配套流程图：`ob/完整程序流程图.canvas`（已同步）、`ob/欠压保存位置及首次校准.canvas`（已同步）

## 1. 工况背景

关窗器：只有关窗需要关紧（过流判定），开窗到固定行程自动停（位置停车）。
原设计按直线推杆（0~1000mm），改为转动机构后行程 0~88°。

## 2. 转动机构参数映射（代码零改动，只换参数）

换算桥梁 = "导程"重解释：**电机转一圈输出端走多少**。直线 = 10mm/圈；转动 = **360°/圈**。
代码是单位无关的数值积分，"mm"只是字段名，数值全按"度"解释。

| 参数 | 直线旧值 | 转动新值 | 说明 |
|---|---|---|---|
| screw_lead（导程） | 10.0 | **360.0** | 输出轴每圈角度（°），非取模换算 |
| stroke（行程） | 1000.0 | **88.0** | |
| reduction_ratio | 10 → 1183 | 1183 | 电机轴 N 圈输出轴 1 圈 |
| hall_pulses_per_rev | 12 | 12 | |
| pulse_to_mm | 0.0833 | **0.02536°/脉冲** | =360/(1183×12)；88° ≈ 3470 脉冲 |
| calib_win A/B | 2.0/2.0 | 2.0/2.0 | REV 校准窗 pos≤2° |
| calib_win C/D | 998/998 | **86.0/86.0** | FWD 校准窗 pos≥86° |
| stop_margin | 4.0 | **0.4** | 位置停车 pos≥87.6° |

校准语义：REV 过流校准成功置 **0°**；FWD 过流校准成功置 **88°**（=stroke）。
窗口与 stroke **代码上零耦合**（独立绝对角度参数）；窗口配到行程外会永久失效，改行程时需人工对齐。

## 3. 机械参数入 Flash A 块（不再写死 .c）

- A 块记录新增 4 float：`rod_stroke_mm / rod_reduction_ratio / rod_hall_pulses / rod_screw_lead`（84B，97 次/擦/扇区）
- 默认宏单点 `dev_param.h`：`ROD_STROKE_DFT / ROD_REDUCTION_RATIO_DFT / ROD_HALL_PULSES_DFT / ROD_SCREW_LEAD_DFT`
- 应用链：`App_Model_Init` 先用 DFT 宏做初值 → `Dev_Param_RodApply` 用 A 块值调 `RodPosition_SetParams` 覆盖（与窗口参数同一应用区，B 块无效也写入）
- 改参数方式：改 DFT 宏 → `param_erase`；或 debugger 改 `g_param_record` → `param_save`
- `calib_tolerance`（校准容差）为无消费点死参数，**已整体删除**（字段/参数/A 块字段/宏）

## 4. 过流检测参数与方向变化屏蔽

| 项 | 值 | 说明 |
|---|---|---|
| 过流阈值 | **1600mA**（原 5000） | 关窗器堵转判定 |
| 判定窗口 | **30ms 连续**（原 50） | 任一 ms 回落即清零重来，非累计 |
| 方向变化屏蔽 | **30ms**（`CUR_BLOCK_MS_DFT`） | 见下 |

**方向变化屏蔽**（启动/换向浪涌期不判过流）：

- 触发端：`MotorGpio_WritePair`（唯一 GPIO 写汇聚点）内，写入方向 ≠ 上次写出方向且进入转动方向（停止→正/反、FWD↔REV 换向）→ `CurrentSensor_ReqBlock(g_cur_cfg.block_ms)`；同向重复写/进入停止不触发；临界区内完成
- 消费端：1ms ISR 屏蔽期**不判定、窗口计数清零**，结束后窗口从 0 重新累计（30 屏蔽+30 窗口 = 最早 60ms 判过流）；`s_fCurrMa` 照常更新可观察
- 参数 `cur_block_ms` 入 A 块（defaults/Apply/Save 回写/打印全链通）；`CurCfg_t.block_ms` debugger 实时可改；0=不屏蔽；SIM 模式同样生效
- 换向为仲裁**一步直达**（FWD→REV 不经停止），靠"方向不同即屏蔽"规则覆盖

**过流检测层打印**（新增）：dispatch 过流分支开头统一打
`[POWER] over curr detect: ma=... th=1600 win=30`（值为 ISR 跳变沿锁存的触发瞬间电流 `CurrentSensor_GetFaultMa`，即堵转/卡阻电流快照；开关 `POWER_PRINT_EN`）

## 5. 电机输出真值表：停止改双高刹车（原双低）

| FWD(PB8) | REV(PB9) | 状态 |
|---|---|---|
| 1 | 0 | 正转（伸出/开窗） |
| 0 | 1 | 反转（缩回/关窗） |
| 1 | 1 | **刹车**（停止/急停/上电默认） |
| 0 | 0 | 滑行（代码已无此输出路径） |

- `WritePair` 停止分支与双高防御分支统一输出双高；`Init` 上电初始态 `GPIO_INIT_HIGH`
- ⚠ MCU 复位期间引脚高阻，到 Init 前电平由外部上下拉决定——若要求复位期也刹车需外部上拉

## 6. 电流灵敏度实测校准（/10）

- 链路排除：ADC 层电流通道 `gain=1/offset=0` 纯出电压；SIM 已关——10 倍偏差在硬件标定
- 标称 5000mA/V（10mΩ×20→200mV/A）实测显示偏大 10 倍 → 等效 **500mA/V**（等效增益 200 或采样电阻实际 100mΩ），`/10.0f` 校准系数并入 `CUR_SENSITIVITY_MA_PER_V`，待硬件量放大器输出确认后转正
- 验证方法：`MONITOR_PRINT_EN=1` 看 `[MON] adc raw=../.. mean=../..mmV`（第二个 mean = 放大器输出 mV），已知电流对比定标

## 7. Flash A 块现状（84B/记录，97 次/擦/扇区）

电压阈值(26/20/1/500ms) + 电流(1600mA/30ms/30ms block) + hall/motor 方向相序 + 校准窗 2/2/86/86 + stop_margin 0.4 + 机械参数 4 项。
**记录布局自本版起多次变更，旧记录 CRC 必失效走 defaults；升级后须 `param_erase` 一次。**
