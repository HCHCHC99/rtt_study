# 电源模块模拟输入（表达式窗口注入）

> 记录日期：2026-08-30
> 用途：无串口/无电源硬件时，用调试器表达式窗口注入母线电压、电流、极性，
> 完整走通阈值判定 → 故障/恢复 → 系统状态机 → 电机仲裁的全链路。

---

## 一、总则

1. 三个模块各有**独立的模式开关宏**（各自头文件内，默认 0=真实模式）：

| 模块 | 开关宏（所在头文件） | 模拟变量（volatile，表达式窗口可改） | 单位/取值 |
|---|---|---|---|
| dev_bus_voltage | `VOLT_SIM_MODE_EN`（dev_bus_voltage.h） | `g_volt_sim_mv` | 母线电压 mV |
| dev_cur_sensor | `CUR_SIM_MODE_EN`（dev_cur_sensor.h） | `g_cur_sim_ma` | 电流 mA |
| dev_polarity | `POLARITY_SIM_MODE_EN`（dev_polarity.h） | `g_pol_sim_state` | 极性态 0~4（含义见第四节） |

2. 开关从 0 改 1 需要重新编译下载；开关为 0（真实模式）时改模拟变量**无任何效果**。
3. 模拟模式下，取数点被替换为模拟变量**直接赋值**（电压的 ADC 换算与 +1.2V 偏置一并旁路；极性跳过 GPIO 与消抖窗口），**下游全部照常**：阈值/迟滞/恢复判定、过压过流事件、g_monitor 镜像、极性跳变的轴事件+仲裁命令。
4. 改模拟变量**实时生效**（1ms 检测 ISR / 2ms 扫描直接读），无需停机。

## 二、dev_bus_voltage（母线电压，mV）

变量：`g_volt_sim_mv`（volatile uint32_t，初值见 .c，调试时可实时修改）。
当前阈值（RAM `g_volt_cfg`，亦可实时改）：过压 `over_th=25V`、欠压 `under_th=0V`（默认关闭）、迟滞 1V、恢复延时 500ms。

| 注入值 | 效果 |
|---|---|
| 22000 | 正常母线（22V），无动作 |
| **26000** | 26V > 25V → 过压跳变：`[POWER] over volt` → EMERGENCY → FAULT，仲裁收到急停 |
| 26000 后改 **22000** | 低于 24V（25-1 迟滞）持续 500ms → `volt normal` 自动恢复 FAULT→原状态 |
| 低于过压阈值的任意值 | 只影响读数显示，无动作 |

注：想让欠压也参与测试，把 `g_volt_cfg.under_th` 实时改成 >0（如 5V），再注入 <4000 即触发欠压。

## 三、dev_cur_sensor（电流，mA）

变量：`g_cur_sim_ma`（volatile uint32_t，初值见 .c，调试时可实时修改）。
当前阈值：过流 `over_th_ma=5000mA`、判定窗口 `window_ms=50ms`。

| 注入值 | 效果 |
|---|---|
| 3000 | 正常（3A），无动作 |
| **6000** | 6A > 5A 持续 50ms → 过流跳变：`[POWER] over curr` → EMERGENCY → FAULT，仲裁收到急停 |
| 6000 改回 500 | 过流不自动恢复（手动恢复语义）：需 `Sys_State_Recover()`（无串口时可由调试器调用，后续可加 debug 钩子） |

## 四、dev_polarity（极性，枚举）

变量：`g_pol_sim_state`（volatile PolarityState_t，初值见 .c，调试时可实时修改）。

| 注入值 | 含义 | 轴事件 | 仲裁命令 |
|---|---|---|---|
| 0 UNKNOWN | 保持上次状态（模拟"不稳定"） | 不发 | 不发 |
| 1 UNPOWERED | 掉电（P=0 N=0） | POWER_LOST | 清正/反允许 → 电机停 |
| **2 FWD** | 正接（P=1 N=0） | POLARITY_FWD | `RUN_FWD` 85% → 仲裁正转 |
| **3 REV** | 反接（P=0 N=1） | POLARITY_REV | `RUN_REV` 85% → 仲裁反转 |
| 4 ABNORMAL | 异常（P=1 N=1） | POWER_ABNORMAL | 清正/反允许 → 电机停 |

注：模拟值直接当作"已消抖的稳定态"，改一次=一次跳变沿；改回相同值不重复发。

## 五、推荐测试序列（表达式窗口逐步注入）

1. 确认三个开关=1（重编下载），系统进 RUN。
2. `g_pol_sim_state=2` → `[POLARITY] fwd` + `[ARB] axis0 fwd duty=85`。
3. `g_pol_sim_state=3` → 仲裁切 `rev duty=85`。
4. `g_volt_sim_mv=26000` → 过压链路 → EMERGENCY/FAULT + 仲裁急停。
5. `g_volt_sim_mv=22000` → 500ms 后自动恢复，仲裁按极性 resync。
6. `g_cur_sim_ma=6000` → 过流 → FAULT（验证恢复需手动）。
7. 观测：`[SM_DIAG]`/`[TH_DIAG]` 每秒行 + `g_arb_dbg_*` Watch 变量。

## 六、注意事项

1. 极性注入只对 di_task 存活时有效（Scan 由 2ms 线程驱动）；di_task 若被饿死（见 INIT卡死 md），注入不生效。
2. 电压/电流模拟在 1ms ISR 内生效；给任务栈留量，勿在 ISR 注入超范围值以外的操作。
3. 模拟结束后把三个开关改回 0（真实模式），重新编译下载。
